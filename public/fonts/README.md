# Fonts

Self-hosted so the site loads nothing from another host (see the
Content-Security-Policy in `netlify.toml`). Latin subset, variable weight.

| File | Font | License |
|---|---|---|
| `archivo-var-latin.woff2` | [Archivo](https://github.com/Omnibus-Type/Archivo), width 62–125%, weight 500–900 | SIL Open Font License 1.1 |
| `jetbrainsmono-var-latin.woff2` | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), weight 400–800 | SIL Open Font License 1.1 |

Both files are the latin subsets served by Google Fonts. The license text is at
https://openfontlicense.org/open-font-license-official-text/.
